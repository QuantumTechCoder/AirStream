# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

AirStream transfers all file data directly between client browsers using DTLS-SRTP encrypted WebRTC `RTCDataChannel` connections. 

If you discover a security vulnerability within AirStream, please do not file a public issue. Instead, please report it via GitHub Private Vulnerability Reporting or email us directly at **quantumtechsperts@gmail.com**.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure.
